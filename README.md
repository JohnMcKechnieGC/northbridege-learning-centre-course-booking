# Northbridge Learning Centre — Course Booking

A small Streamlit application for booking courses at Northbridge Learning Centre.

## Run locally

1. Create and activate a Python virtual environment.
2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Start the application:

   ```bash
   streamlit run streamlit_app.py
   ```

4. Open the local URL shown by Streamlit.

## Streamlit Community Cloud

Use `streamlit_app.py` as the main file and install dependencies from `requirements.txt`.
